# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.




# Personal Portfolio Website

## Project Overview

This is a responsive personal portfolio website built using React and CSS. The website showcases my background, technical skills, projects, and contact information in a professional and modern layout. It is designed to highlight my experience as a web developer and provide an easy way for recruiters and employers to learn more about my work.

The portfolio includes:

- Hero section with introduction
- About Me section
- Technologies & Tools section
- Skills section
- Projects showcase with images and descriptions
- Why Companies Should Hire Me section
- Contact information
- Responsive design for desktop, tablet, and mobile devices

---

## Technologies Used

- React
- JavaScript (ES6+)
- CSS3
- HTML5

---

## How to Run the Project Locally

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Navigate to the project folder

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

Vite will provide a local URL similar to:

```txt
http://localhost:5173
```

Open the URL in your browser to view the application.
